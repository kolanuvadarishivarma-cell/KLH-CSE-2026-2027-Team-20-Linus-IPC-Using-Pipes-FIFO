How Named Pipes Work

  • Filesystem Presence:

    Created with mkfifo("/tmp/relay_a_to_b", 0666). Both independent programs open this same file path.

  • Blocking Synchronization:

    open(O_WRONLY) blocks until the other process opens O_RDONLY. No sockets or networks are needed!

  • Two-Way Communication:

    A FIFO is unidirectional. Two FIFOs (A→B and B→A) enable full-duplex two-way chatting.

  • Check Terminal:

    Look at your terminal running ./server to see real-time [FIFO SEND] and [FIFO RECV] logs!
